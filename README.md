# Recordock

Record your screen. Keep it local.

Recordock is a privacy-focused Chrome screen recorder that records one selected browser tab, application window, or monitor and saves the completed recording locally as a WebM file.

## Project status

Recordock is currently under active development.

## Planned initial release

Version `0.1.0` will support:

- Browser-tab recording
- Application-window recording
- Full-monitor recording
- Available tab or system audio
- Background recording through an offscreen document
- Recording timer and status
- Local WebM preview
- Local WebM download
- No account
- No cloud upload
- No backend

## Technology stack

- React
- TypeScript
- Vite
- Manifest V3
- Chrome Extensions API
- MediaRecorder API
- Vitest
- React Testing Library

## Privacy

Recordings will be processed locally in the browser and remain on the user's device.
